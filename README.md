## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is designed to be a clean utility that modifies application files to enable features. However, as with any tool that alters software, you should always download from trusted sources, scan with anticomponent, and understand the potential risks of modifying application behavior.

### Which AI applications does OmniPatch currently support?

OmniPatch supports patching for ChatGPT desktop, Claude desktop apps, Microsoft Copilot, GitHub Copilot extensions, Cursor editor, Perplexity desktop, JetBrains IDEs with AI Assistant, and Devin's AI agent interface.

### How frequently is OmniPatch updated for new AI app versions?

Updates are released on an ad-hoc basis, typically within 1-2 weeks after a major version update of a supported AI application is detected to ensure continued compatibility.

### Will using OmniPatch affect my official AI service account or subscription?

OmniPatch modifies the local client application on your Windows PC. It does not interact with or alter your online account, subscription status, or server-side permissions of the AI services.

### Can OmniPatch be detected by the AI applications as unauthorized modification?

Patched applications may show different startup logs or lack digital signatures. We recommend using OmniPatch on devices where you control the security policies and understand the nature of the modifications.

### Is there a version for macOS or Linux?

OmniPatch is currently a Windows-only desktop tool. There are no official plans for macOS or Linux versions at this time.

### Does OmniPatch require an internet connection to work?

The patching process itself is performed offline after downloading the tool. However, the patched AI applications will still require their own internet connections to function normally.

### What should I do if an AI application stops working after patching?

First, ensure you have the latest version of OmniPatch compatible with that application's version. You can also try uninstalling the AI app, reinstalling it, and then re-running OmniPatch.
